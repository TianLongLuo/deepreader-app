# 语境词库与 FSRS 复习验收

## 已验证（本地隔离工作树）

- 旧收藏仅解析已知字段；损坏 JSON、纯文本、混合语言 AI 和词典许可均保留原始证据。明确语言的语境义与未分类旧释义分开，不以词典第一义冒充本句义。
- additive SQL 只新增学习表；版本与 SHA256 校验、显式绝对数据库路径、事务、foreign_key_check/quick_check，重复执行不覆盖已有状态。
- ReadingEntry 与义项/出处/空卡同事务保存；不同用户/工作空间及已删除文档隔离。未确认同义不按拼写合并。
- ts-fsrs **5.4.2** 官方默认排程，Date 还原及完整 learning_steps/reps/lapses；旧 reviewCount 不制造虚构历史。旧 PATCH 评分绕过入口返回 409。
- 正面 DTO 与初始 DOM 不含释义/词典；翻面在服务端记录。会话30分钟，绑定卡版本、义项修订与出处。两窗口、幂等重试、过期、外部用户、修订冲突均有测试。
- 人工释义/标签独立；CAS 编辑和旧任务冲突防覆盖。生成建议写入口默认关闭，下一阶段仅由持久化、已领取整理任务验证器开放。
- 紧凑列表支持搜索/语言/词性/领域/状态、稳定游标；本句义优先，技术数据折叠。待整理词保留，但无答案卡不计入可复习数。
- 三主入口：词库 / 复习 / AI练习；次级阅读记录保留笔记、书签、保存对话及原文位置。AI练习当前明确为阶段三待接入，**不是全部功能完成**。

## 无损副本演练（spec §6–7）

`tsx scripts/qa/vocabulary-migration.ts` 使用临时 SQLite，涵盖英语同形不同义、西语同形词、损坏 note、旧计数、人工修订、已删除文档及三种非词记录。迁移中断于首个已提交出处后，在数据库副本上重跑两次；每条 ReadingEntry 全字段深比较相等。

真实 FSRS 翻面／Good 产生一条日志和 version=1，重新迁移后全部卡和日志深比较不变。故意执行第二条失败的 SQL 验证整个事务回滚、版本未记录、再跑完整迁移恢复，foreign_key_check 为空且 quick_check=ok。此脚本为自动测试的一部分。

spec §6 的页面／键盘／隐藏答案证据与 §7 的原始证据／排程／无损迁移分别验证，不以数据库快照相同代替复习正确。最终独立全分支审查及生产副本／上线验证在第三阶段联合门禁执行。
