# 阅读与 AI 功能更新

- 阅读进度、书签、笔记和高亮按用户保存；旧版本地书签在同步成功后迁移。
- 书库支持搜索、重命名、排序和进度显示；阅读器支持字号、行距和移动端导航。
- EPUB/PDF 支持全文搜索并跳回原文。搜索最多返回 80 项，超出范围会提示。
- AI 支持快速/深入解释、翻译、上下文追问、难度选择、当前章节/页面摘要和理解测验；支持取消、重试、引用原文和保存对话。长文本会按界面提示截取，摘要不能视为整本书结论。
- 查词支持手动输入或选词，显示英文释义、音标和可用发音；可另行请求 AI 结合原文解释。外部词典不可用时仍可保存生词。
- 学习库集中管理词汇、笔记和对话，支持复习及 CSV 导出。

## 部署

本次新增两张 SQLite 表。先备份数据库和上传文件，再按 [部署说明](../src/server/reading/DEPLOYMENT.md) 执行 `npm exec prisma db push`、生成客户端、构建和重启。不要使用强制重置或接受数据丢失参数。代码推送不等于生产数据库已升级。

词典依赖部署环境能够访问 dictionaryapi.dev（英语）和 en.wiktionary.org（西语），词典音频还需要对应媒体站点可达；AI 使用现有模型设置。自动测试使用模拟 AI，不会消耗生产 API 配额。词典网络失败会提示重试。

## MiMo 与西班牙语

在 `/dracconsole` 填好 MiMo 模型名称、密钥和接入方式，点击“保存并启用 MiMo”。支持按量付费与 Token Plan 中国、新加坡、欧洲接口。普通用户使用全局配置需要打开 Shared AI；该开关保持独立，保存密钥不会自动改变共享权限。可以先点击“测试已保存的 MiMo 配置”，测试会产生一次真实请求并验证 JSON 输出；成功信息同时说明 MiMo 是否已启用、是否共享。密钥加密存储，界面只返回脱敏预览；未填写新密钥时保留原值。

前端 AI 回答和语境释义会显示本次请求配置的 provider/model。已启用 MiMo 后缺少密钥会明确失败，不再静默切换到旧 DeepSeek；修改地区接口或轮换密钥也会使旧回答缓存失效。阅读请求关闭 MiMo 默认思考模式，避免思考内容耗尽为正文设定的短输出额度；完整性和截断检测仍执行。依据 [MiMo 思考模式文档](https://mimo.mi.com/docs/en-US/quick-start/usage-guide/text-generation/deep-thinking)。

联调测试覆盖后台保存 → 配置解析 → MiMo HTTP 参数 → 前端七种阅读模式（英语/西语）、共享权限、密钥清除和轮换、地区变更以及流式输出。自动测试模拟上游返回，不代表线上账号的密钥、套餐余额或模型权限已验证；上线后应执行一次后台连接测试并在阅读器发起新请求。

Token Plan 是接入套餐，不是单独的模型名；请填控制台允许的具体模型，例如 `mimo-v2.6-pro`。套餐使用 `tp-` / `ttp-` 密钥，按量付费使用 `sk-` 密钥，地区以控制台为准。参见 [MiMo 官方快速接入](https://mimo.mi.com/docs/zh-CN/tokenplan/Token%20Plan/quick-access)。

阅读工具顶部可选择英语或西班牙语，选择会保存在当前浏览器。西语 AI 支持变位、性数一致、隐含主语、ser/estar 和虚拟式等分析；生词及对话保存语言，学习库可按语言筛选，回到原文时恢复词条语言。旧的未标记生词默认归为英语。

两种语言都支持独立词典查询和 AI 语境释义。西语词典采用 Wiktionary 的 Spanish 分区，显示音标、词性、英文释义、可用例句及音频，并保留来源和许可；AI 解释与词典内容分开标记。词典保存与导出保留署名。英语的 pie 与西语的 pie 可分别保存，重复收藏可补充释义且不重置复习记录。

西语不会使用英语默认语音：有词典录音时可播放录音，否则使用设备安装的西班牙语语音。设备没有对应声音时给出明确提示。详细解析不会再补写基于英语词尾规则的时态；重音与 ñ 被完整保留，原文高亮必须匹配真实片段。

验收包括真实公开词典查询（niño、corazón、estuviera、pie），以及复杂西语的模拟模型集成测试（省略主语、虚拟式、关系从句、精确高亮、修复失败不缓存、取消与语言隔离）。这些检查验证功能与数据处理，不能代替对实际配置模型的教学质量评测。

本次 MiMo/西语更新无需新增数据库表；首次安装上一版阅读功能时仍需完成上文数据库升级。

## PDF 格式兼容

EPUB 和 PDF 共用同一阅读栏：上一页/下一页、目录与书签、添加书签、全屏。EPUB 随屏幕重排；PDF 的「随屏排版」同样按屏幕宽度显示可学习文字，「书页排版」保留图片、表格和多栏版式。排版选项替代之前分开的“文字学习/PDF 原版”模式。书页由服务端逐页渲染 PNG，不依赖浏览器 PDF 插件，支持适宽/100% 缩放；仍可打开原文件。

PDF 正文改为最长约 72ch / 800px 的连续单列，使用统一字号、行距和主题，不再给每个物理页强制预留整屏空白。轻量页码分隔保留原书定位。解析会合并机械换行；单块正文页根据文字坐标恢复段间距和明确的双栏顺序，保留西语重音、真实连字符及独立空格。为兼容旧段落书签，保留原提取块数量，块内自然段通过留白显示。旋转文字、部分表格及无法确定的布局保留原提取顺序，可切换书页核对。

PDF 页码使用物理页序（含封面、空白页），可能与印刷页码不同。两种排版都保存阅读进度并支持书签，再打开同一本书会恢复位置及对应排版。书页只有加载成功后才保存页码；定时同步之外，页面进入后台时也会尝试同步。书页位置使用文档专属的 `pdf-page:` 标识，旧段落书签保持兼容，无需数据库迁移。

随屏排版跳到无文字页时会显示书页；整本无可提取文字时自动采用书页排版。点击“学习本页”会定位到同页已提取文字并打开阅读工具。书页图像本身不能直接选词，扫描页仍需先做 OCR；界面会明确提示，而不会拿别页文字冒充当前页。

分页图像沿用文档工作区鉴权，仅在用户浏览器私有缓存。单次只渲染一页，画布边长及像素数有上限，单进程同时最多渲染两页，避免长书一次渲染耗尽内存；忙碌或加载失败时可重试。服务端必须具备项目已有的 `@napi-rs/canvas` 原生依赖运行环境。

已修复中文书名导致原 PDF 响应头失败、浏览器尾部字节和越界 Range 请求、正文与分页标记冲突的问题。初始文字及元信息提取后释放 worker，再通过公开 pdf.js API 读取布局坐标；首次提取有额外解析开销，接口沿用文字缓存。

当前没有内置 OCR，也未保证复杂多栏、公式和表格的文字提取顺序；原版模式用于完整查看这些内容。扫描书需先经过 OCR，才能在文字模式查词及分析。此次更新无需数据库变更，构建并重启服务即可生效。

## 上传、删除与阅读状态修复

删除书籍会先保存 `DELETING` 状态，再清理原文件和数据库。中途失败时书库保留“重试删除”入口，暂停该书的阅读及 AI 操作，避免把文件已删除的书显示为可正常阅读。本地文件权限或磁盘错误不再被当作删除成功；文件已不存在时允许重试完成剩余清理。删除确认会说明进度、笔记、生词和 AI 记录也会移除。

上传或数据库登记失败会尝试清理此次唯一存储路径；如果存储本身持续不可用，清理错误和路径会写入服务端日志，供运营排查。

同一阅读器的进度请求改为顺序发送，并合并快速翻页产生的待保存位置，减少慢网络下旧请求覆盖新位置的问题。失败后继续按现有定时同步机制重试；切换书籍或用户会重建阅读器状态。这不解决多个设备同时阅读同一本书的写入冲突。

全文搜索支持跨 PDF 硬换行的短语，并保留西语重音字符；修复无空格连续句的分句偏移，避免后续句子高亮错位。切换选段会清除旧请求的重试入口。本轮无需新增数据库字段。
