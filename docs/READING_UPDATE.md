# 阅读与 AI 功能更新

- 阅读进度、书签、笔记和高亮按用户保存；旧版本地书签在同步成功后迁移。
- 书库支持搜索、重命名、排序和进度显示；阅读器支持字号、行距和移动端导航。
- EPUB/PDF 支持全文搜索并跳回原文。搜索最多返回 80 项，超出范围会提示。
- AI 支持快速/深入解释、翻译、上下文追问、难度选择、当前章节/页面摘要和理解测验；支持取消、重试、引用原文和保存对话。长文本会按界面提示截取，摘要不能视为整本书结论。
- 查词支持手动输入或选词，显示英文释义、音标和可用发音；可另行请求 AI 结合原文解释。外部词典不可用时仍可保存生词。
- 学习库集中管理词汇、笔记和对话，支持复习及 CSV 导出。

## 部署

本次新增两张 SQLite 表。先备份数据库和上传文件，再按 [部署说明](../src/server/reading/DEPLOYMENT.md) 执行 `npm exec prisma db push`、生成客户端、构建和重启。不要使用强制重置或接受数据丢失参数。代码推送不等于生产数据库已升级。

词典依赖部署环境能够访问 dictionaryapi.dev；AI 使用现有模型设置。自动测试使用模拟 AI，不会消耗生产 API 配额。词典网络失败会提示重试。

## MiMo 与西班牙语

在 `/dracconsole` 保存 MiMo 模型名称、密钥和接入方式，再将 Active Shared Provider 切换为 MiMo。支持按量付费与 Token Plan 中国、新加坡、欧洲接口。可以先点击“测试已保存的 MiMo 配置”，测试会产生一次真实请求。密钥加密存储，界面只返回脱敏预览；未填写新密钥时保留原值。

Token Plan 是接入套餐，不是单独的模型名；请填控制台允许的具体模型，例如 `mimo-v2.6-pro`。套餐使用 `tp-` / `ttp-` 密钥，按量付费使用 `sk-` 密钥，地区以控制台为准。参见 [MiMo 官方快速接入](https://mimo.mi.com/docs/zh-CN/tokenplan/Token%20Plan/quick-access)。

阅读工具顶部可选择英语或西班牙语，选择会保存在当前浏览器。西语 AI 支持变位、性数一致、隐含主语、ser/estar 和虚拟式等分析；生词及对话保存语言，学习库可按语言筛选。英语免费词典不能提供西语定义，西语通过“AI 语境释义”查询，结果明确标为 AI 内容。旧生词默认归为英语。

本次 MiMo/西语更新无需新增数据库表；首次安装上一版阅读功能时仍需完成上文数据库升级。
