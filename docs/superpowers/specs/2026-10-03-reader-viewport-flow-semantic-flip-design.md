## 1. 已确认的目标

1. 开启意群阅读后，优先处理当前实际可见内容，后台处理前后各两屏。窗口随翻页／滚动移动，包括相邻章节，不只处理初始页面。
2. EPUB 可在横向分页和纵向连续阅读之间切换；记住偏好，保留阅读位置，适配现有阅读工具。
3. 增加可独立选择目标语言的语义翻牌。开启后禁用正文手势触发的查词、句子结构和段落解析浮窗，点击单词仅替换该次出现，再点恢复。与意群阅读可同时使用。
4. 目标语言提供英语、中文、西语；用户已确认，英语阅读选择英语时，生成符合当前语境的简明英文同义词或短语。
5. 原文数据、引用、书签和进度保留原文语义位置。较长替换参与正常换行，不以悬浮遮罩覆盖邻词。

首期正文范围为可重排 EPUB 和已有的 PDF 随屏文字模式。PDF 原书页、固定版式 EPUB 保留现有查看方式；扫描 PDF 沿用此前约定，不新增 OCR 或图片文字层。原有词库、FSRS、AI 练习、离线词典和账号权限不重构。

上线只更新 DeepReader 项目。数据库结构、上传书籍、已有学习记录、模型密钥、系统登录配置、其他站点和其他服务保持不变。

## 2. 现状与证据

### 2.1 意群调度

- `use-meaning-group-reading.ts` 只向队列提交当前可见文本；排除视口外 iframe，没有邻屏预取。
- `meaning-group-queue.ts` 在单元离屏时取消请求，且仅缓存仍可见的成功结果。
- 401／403／503 和耗尽退避的 429 会暂停全局队列，翻页不会主动解除。离线 mock 已复现：503 后新页保持 pending、blocked；显式重试才请求新页。这不是某次线上报错的取证结论。
- 服务端已有每用户 2 个 active、每分钟 24 次 provider acquire；输出修复也计入次数。测试 mock 的快速成功不代表真实额度足以即时完成所有邻屏。

### 2.2 阅读模式

- `ReactReader` 当前使用默认 EPUB 分页。PDF 随屏文字模式本身已经纵向连续。
- 安装的 react-reader 只在初始化读取 `epubOptions`。仅更新 prop 不会切换 manager。
- 当前 `hooksRegisteredRef` 是组件级布尔值，重建 rendition 后会漏注册新实例的 hooks。
- 当前 EPUB wheel handler 总是拦截并翻页；纵向需要放行原生滚动。
- 恢复位置尚未完成时，现有保存逻辑存在将临时位置覆盖已保存位置的竞态。

### 2.3 翻牌与原文定位

- 当前采集、意群 Range、选词、引用、CFI 都读取显示 DOM 的文字。
- 只修改单词的显示文字会改变其后 UTF-16 偏移。已用 jsdom 复现：`CAT` 换成更长单词后，原本指向 `after` 的 CFI 直接解析到修改后的 DOM 会命中错误文本。
- `ignoreClass` 使用当前文字长度计算偏移，解决部分包装节点问题，但不解决长短词替换。
- epubjs 内部页面位置和选区事件直接构造 `EpubCFI`，因此只包装应用层 `cfiFromRange` 覆盖不足。
- 安装的 `Mapping.findRanges` 存在循环条件缺陷，本方案不依赖该函数枚举邻页。

## 3. 选定方案与架构边界

采用现有 EPUB 引擎的增量适配，不建立新的整书纯文字阅读器，不一次性向 AI 发送整本书。

### 3.1 阅读流适配器

可重排 EPUB 的两个模式统一使用原引擎 continuous manager：

| 模式 | flow | 交互 |
| --- | --- | --- |
| 横向分页 | paginated | 保留分页、双页 spread 和前后翻页 |
| 纵向连续 | scrolled-continuous | 单列、原生滚轮／触摸滚动，前后按钮移动一屏 |

这样相邻章节由同一个 manager 的 buffer 提前加载，不创建第二个 rendition、不修改共享 section 文档，也不使用另一个引擎模拟预取。横向分页的既有观感及操作必须通过真实 EPUB 回归后才交付。

buffer 根据实际阅读轴设置为前后各两屏：分页使用完整一屏／spread 的 layout 步长；纵向使用实际裁剪后的阅读区高度。resize、字体、行距、主题字体资源、模式和翻牌投影重排后重新计算。设置 manager buffer 后触发 check/update；仅可测量、已加载的内容才成为来源，不把整章存在 DOM 解释为整章 AI 处理。

PDF 文字模式使用现有滚动容器和物理页标记。其横向分页选项不出现；原书页查看保持独立。

### 3.2 原文与显示投影

为当前 EPUB view／PDF 文字块建立三层模型：

1. canonical：不可变原文 DOM 快照、原始 Text 字符串、原文位置。
2. live：引擎真正显示和测量的 DOM。
3. projection：原文区间和显示区间的有序片段表、节点配对及出现位置标识。

翻牌只更新 live Text.data。书籍源文件、spine section 原文、canonical 快照和数据库文字均不改写。正文不因翻牌新增包装、拆分、删除或 normalize 节点；这与“显示 DOM 从未改变”不是同一个承诺。

译词参与浏览器真实排版。限定正常 prose 的换行样式，使词或短语有必要时正常换行，不绝对定位、不截断、不缩成难辨小字。译文继承原词起始文字片段的样式。

同一个词多次出现分别用 canonical CFI 或 PDF 段落 ID + 原始偏移定位，绝不全局字符串替换。跨 `<em>`／`span` 等内联节点的词作为一个原子出现位置处理：完整译文投影到首个片段，其余被覆盖片段显示为空，原节点仍保留。

首次建立配对必须来自没有临时句法包装的 pristine view。开启翻牌时关闭浮窗、清除句子聚焦和临时注释，并在必要时以保留锚点的方式重建 view。旧解析请求和迟到回调不得继续包装正文。

### 3.3 集中式 canonical CFI 适配器

在客户端对实际 epubjs 使用的同一个 `EpubCFI` 构造函数安装按 Document 注册的适配器，覆盖 `fromRange`、`fromNode`、`toRange`。不修改 node_modules 文件，不改动未注册文档的行为。

- fromRange/fromNode：显示端点转到 canonical，再用原有算法序列化。
- toRange：CFI 在 canonical 文档解析，随后映射为 live Range，供 display、位置测量和注释使用。
- 内部 Mapping、Contents 选区事件、应用选词、书签、曝光、导航共用这层规则。
- locations 索引、section 搜索和 Book.getRange 继续读取未投影原文，不把 detached canonical Range 当作可见几何。
- 章节卸载解除注册；多个 reader 实例通过独立文档域隔离，最后一个使用者卸载时安全恢复安装的入口。
- 浏览器构建必须验证导出类与内部类身份，以及内部 relocation 确实经过适配入口。此项是交付前的硬性测试，不以 CJS 单测替代。

未替换区间精确双向映射；替换内部是多对一原子区间，使用明确端点偏置。由旧 CFI 解析出的 Range 附原文 origin 元数据，保证旧 CFI 的解析／重序列化保留位置；用户新点击译文内部则定位原词，而不是虚构一个译词内部原文字符位置。

每次批量更新 Text.data 后执行投影事务：暂停对新几何的位置上报，主动触发 epubjs 内容尺寸检查／view expansion，等待更新后的 iframe 尺寸和分页列数稳定，再执行 manager buffer check/update、Mapping 和位置上报。恢复被影响的 canonical 视口锚点后解除暂停。只依赖 ResizeObserver 不足以检测增加／减少列数；尺寸同步由 pinned 引擎适配器显式负责。

正常重排会改变行号、显示页数和页内坐标；原文进度和书签稳定，不承诺显示页码恒定或每个显示页具有不同原文 CFI。

### 3.4 统一正文访问

新增统一 originalText／originalRange／projectedRanges 接口。以下业务读原文，不再直接拿投影后的 textContent 作为语境：

- 意群文本采集、单元切分、结果校验与缓存键。
- 查词、段落解析、翻译、追问及引用跳转。
- 书签标签、笔记文本、原文位置及阅读接触记录。
- 替代节点查找、章节内容与重复词识别。
- 翻牌模式的复制行为：复制原文选区；翻牌完成／恢复的无障碍公告明确原词与译词，公告中分别标注源／目标语言；不为设置 lang 而包装正文。

元素结构、隐藏状态和 computed styles 仍取自 live 文档；文字和规范化偏移取 canonical。不要使用 detached clone 的 computed styles 判断正文或可见性。

## 4. 意群阅读：滚动窗口与优先级

### 4.1 三个集合

- visible：当前实际可见的原文单元，控制显示状态、高亮和阅读 exposure。
- neighborhood：当前屏 + 前后各两屏对应的原文单元，控制处理目标和在途保留。
- loaded：引擎加载的文档，仅提供可测量来源，范围外文字不进入 AI 任务。

每个单元先按完整 canonical passage 使用现有空白规则和 `splitMeaningText(...,1200,language)` 确定，再按投影后的真实 Range 矩形筛选。不可先截断邻屏文字再切单元，以免和未来可见页面产生不同边界／缓存键。

### 4.2 队列规则

1. 当前 visible 最高；随后按近期阅读方向优先第一邻屏、反方向第一邻屏，再第二邻屏。
2. visible 变成 neighborhood 内预取时保留在途请求；离开整个目标窗口后取消。
3. validated complete 才进入缓存；partial prefix 可用于当前可见单元即时高亮，但不作为完整成功或 exposure。
4. 同文本请求合并；位置相同／不同通过单独来源记录区分，不重复收模型结果，也不遗漏新的实际阅读出处。
5. 取消的任务及时释放调度槽，旧 Promise 结束后用 task identity／generation 防止删掉新的任务。
6. 可见内容不因数量或字符预算被截断。邻屏任务最多保留 16 个待执行单元、19,200 个原文 UTF-16 字符，按成功、取消和窗口变化滚动补位，超出部分标记 deferred，继续属于目标范围。
7. 总 AI 执行并发上限为 2；纯预取最多占 1 槽，按每分钟最多 8 次新启动控制额外调用。真实可见处理及点击翻牌优先，既有 provider acquire 总额度仍为每分钟 24（修复也计入）。统一新增两项业务的服务端额度状态，cache hit 不计新 provider 调用。
8. 缓存仅存原文及结果，不存旧 DOM Range。保留最多 128 单元、总原文 153,600 字符的 LRU，并按用户／文档／源语言／版本隔离。几何改变不清掉正确分析结果。

### 4.3 暂停与错误

- 429 读取 Retry-After；暂停启动新任务，尽量保留正在正常运行的任务。有限退避预算跨滚动窗口保存，不因换页归零；等待、到期恢复和退避耗尽显示不同状态。
- 401／403／配置类 503 明确提示检查登录／权限／AI 设置，等待显式重试；不暗中反复付费请求。
- 单元校验失败保留该单元原文，提供重试；不使其他成功单元消失。
- 关闭意群、换文档或换源语言取消相关工作；主题／低饱和度只重绘，不销毁网络队列。

### 4.4 事件与接触记录

连接 relocated、rendered、iframe load、resize、scroll、投影 epoch；通过 requestAnimationFrame 合并刷新，400 ms 轮询仅作兜底。

预取不是阅读。只有真实 visible 且 validated complete 或命中完成缓存的单元按 canonical 来源位置记录 exposure。隐藏邻章、buffer views、恢复位置期间和未完成 prefix 均不计入。

## 5. 垂直阅读与位置恢复

新增按账号保存的阅读流偏好；已有用户未选择时继续分页，不改已有主题、字号和词典展开偏好。

切换流程为 `loading → restoring/switching → ready`，错误进入可见 error 状态：

1. 捕获最近一次已确认的 canonical viewport 锚点，并关闭未固定浮窗。
2. 暂停进度提交、曝光、预取和投影应用；保留已完成缓存和本次会话的翻牌记录。
3. keyed 重建 ReactReader，并以 canonical 锚点显示。每个 rendition 注册独立的 content、progress、style、interaction hooks，清理旧实例监听器与异步任务。
4. display 完成后，在恢复事务内重新绑定已完成翻牌投影，主动同步引擎尺寸并等待几何稳定，再次定位 canonical 锚点。最终实际内容渲染且 relocated 范围包含锚点后才进入 ready。分页会对齐页首，验收不是要求新页首 CFI 与捕获值完全相等。
5. ready 后绘制意群，恢复串行进度保存、曝光和预取。恢复／卸载期间仅提交最后确认快照，不提交临时书首位置。

纵向放行原生滚轮和触摸；前后按钮标为上一屏／下一屏，保留目录和书签定位。字号、行距和窗口变化按同样的锚点规则处理。

浮窗继续是真正浮层，不占阅读父容器，不挤正文。未固定浮窗在滚动时收起；固定浮窗跟随可见来源，来源离屏后提供返回原文。顶部工具栏保留默认隐藏、靠近顶部出现、移开收起及键盘／触摸入口。

## 6. 语义翻牌行为

### 6.1 开关与语言

在阅读工具条放置独立复选开关和紧邻的目标语言选择，不复用查词的 explanationLanguage。

偏好按账号保存，开关初始为关。未选择目标语言时：西语正文默认英语，英语正文默认英语；同语目标输出简明同义表达。三个目标语言均可手动选择，按源语言保存选择。

模式生效时立即关闭单词、句子、段落浮窗，包括固定浮窗。对正文的单击、段落边缘、Enter、选择单词／句子／段落以及快捷分析入口统一采用模式策略，避免某个旧监听器仍弹窗。词库、目录、书签和常规设置入口保留。

键盘路径固定为 Alt+Enter：优先判断选区是否完全属于一个已翻牌 occurrence；若是则恢复整个 occurrence，包括选择完整多词译文的情况。其余选区仅当对应一个原文单词时发起翻牌；多词原文、多段或跨 occurrence 选区不触发翻牌或解析。Escape 取消对应在途任务，或恢复最近一次已完成翻牌。

隐藏浮窗不是只修改 CSS：相关解析组件卸载、请求取消，迟到回答不应用，防止后台继续查词／分析。

### 6.2 单次翻牌

1. 从显示命中点还原 canonical 单词出现位置，跨内联节点使用原文映射识别完整词。
2. 以原词所在原句／有界段落和必要邻句向服务器请求短表达，不发送整章或整本书。
3. 原词在等待期间仍显示，仅添加轻量处理状态；保留阅读和对其他词的点击。
4. 流式协议返回状态和最终短表达，只有 complete 且校验成功时才原子应用翻牌。不展示半截 JSON 或未经校验的替换。
5. 点击译文任意部分恢复整个原词，不调用 AI；处理中再点取消。
6. 同词其他出现位置不变；仅当前 occurrence 可变为词或短语，不翻译邻词或整句。
7. 一次最多保留 2 个未完成点击任务，超过时以最近点击优先取消最旧任务，反馈处理中状态，服务端仍执行公共额度。

关闭模式恢复所有原词。改变目标／源语言取消旧请求并恢复当前投影；新语言的译文不会和旧语言混用。翻页和 mode 重建在当前会话内按 canonical occurrence 重新绑定已完成结果；刷新后默认显示原文，保留开关及语言偏好。会话缓存有界，不把每次翻牌写入词库或复习记录。

失败时保留原词，以工具栏短状态和 aria-live 提示，不重新打开被禁用的解析浮窗。

### 6.3 语境与格式

英语→英语、西语→西语输出更易理解的当前义项表达；跨语言输出适合该语境的短对应表达。保留需要的词形、大小写和语法关系；已有简单词无必要替换时可原样返回，提示“已是简明表达”。

允许简短多词表达作为一个替换单元。禁止返回长解释、一般词典多义列表、例句、Markdown、换行和 HTML。译文是纯文本，不作为代码／HTML／指令执行。

## 7. 服务端接口与数据域

新增语义翻牌路由和服务，不复用当前返回长解释的 word 模式。沿用现有登录、workspace、文档状态检查、服务端 AI 配置解析和 NDJSON 流设施。

输入为：documentId、sourceLanguage(en/es)、targetLanguage(en/zh/es)、原文 sourceText（最多 6,000 UTF-16 字符）、start/end、targetWord（最多 120 字符）、canonical occurrence 标识（最多 2,000 字符）、可选 previousText/nextText（各最多 1,500 字符）。客户端截取上下文时同时重算单词偏移。服务端严格校验区间、原文 slice 等于 targetWord、字段枚举及请求体大小；用户／workspace 不由请求体指定。

输出只包含 replacement（不超过 120 字符、最多 6 个空白分词单元）及可公开模型标识。仅结构和长度验证成功后 complete；语境正确性另由英语／西语固定验收样例和人工检查覆盖，不把格式合法冒充语义正确。

模型请求是服务端流式，timeout 30 秒、输出 token 预算有界；至多一次格式修复，修复也计额度。原文包在不可信数据字段，系统提示禁止执行原文指令。provider 凭据和内部错误不回传客户端。

服务端缓存键包含 user/workspace、文档、原文及精确 occurrence、源／目标语言、模型／设置 hash、提示版本。遵循管理员 cacheEnabled；仅缓存完成且校验成功结果，缓存最多 256 条、TTL 24 小时。客户端会话复用仅限本次原文／语言／配置域；读者修改 AI 设置后清理相关会话结果。

没有新增数据库表或迁移。阅读进度、书签、笔记和学习 exposure 仍写既有接口和 canonical 数据。

## 8. 拆分边界与改动范围

从庞大的 ReaderLayout 抽取本次需要的模块，而非重构整个阅读系统：

- reading-flow adapter：manager 配置、窗口几何、ready／restore 生命周期。
- original-text + source-position：不可变来源、节点配对、PDF／EPUB canonical 位置。
- text-projection：原子 occurrence 片段、命中转换、恢复和投影 epoch。
- scoped-cfi adapter：客户端 EPUB 内部和外部入口适配。
- meaning-window scheduler：visible／neighborhood、优先级、缓存、预算和错误状态。
- semantic-flip client/server：请求取消、严格短输出、缓存和服务端额度。
- reader-mode policy：弹窗／选择／复制／快捷键的一致路由。

既有 meaning source、highlights、study-interaction、selection-anchor、progress-sync、reader-toolbar、阅读设置及 ReaderLayout 接入这些模块。既有 AI NDJSON、鉴权和配置服务复用。暂不增加生产依赖或升级 epubjs／react-reader。

## 9. 验收矩阵与交付门槛

### 9.1 离线与自动化

- 连续翻页至少 10 屏、双向翻页、跨 3 个短章节；窗口跟随，目标范围外无 AI 请求。
- 队列可见优先、预取最多 1 槽、16 单元和字符预算、公共额度、取消释放槽、迟到回调、429 跨窗口退避、503 显式恢复。
- 缓存命中重绘；相同文字不同位置只记录真实可见的来源。主题切换不取消在途处理。
- 原文与 projected 长短词双向映射；重复词、跨 inline 节点、重音、弯引号、代理对、缩略／连字符和多次组合翻牌。
- 英语／西语与三个目标语言；同语简化；短输出格式、错误／取消、文档归属、未经登录、配置失败、prompt injection 数据隔离。
- 所有手势和快捷入口都不挂载解析组件、不调用查词／段落 API；关闭模式后原行为恢复。
- 保存的旧 CFI、书签、note、source exposure 稳定；内部 Mapping／选区序列化和 navigation 全路径经过适配。
- 恢复状态先于保存，切换两次以上不漏 hooks；字体变化、刷新、pagehide 不覆盖真实阅读位置。
- 偏好按账号隔离；存储受限时功能仍可操作；新设置不改已有词典展开状态或主题。

### 9.2 真正浏览器验收

使用无私人内容的本地英文／西语合成 EPUB（含多个短章节、内联样式、双页 spread）和文本 PDF，mock 模型和 API，不用整本用户书籍做调试材料。

- 验证 epubjs 类身份与内部 CFIs，不以静态 markup 或 jsdom 代替。
- 较长译词自然换行，日间／夜间／纸色均不覆盖邻词；意群背景和动词强调延伸至完整译文。
- 页内底部翻牌、多次翻牌、跨页词、恢复、跨章回看与字号变化后的原文定位。
- 章节末尾翻牌导致分页列数增加／减少时，iframe 尺寸更新、末页可达性及原文位置恢复正确；不以根盒 ResizeObserver 触发作为唯一证据。
- 原生连续滚动、触摸、键盘、目录／书签／笔记跳转、顶部自动收起及浮层位置。
- 翻牌模式复制原文、Alt+Enter 选词翻转／恢复、Escape、公告的源／目标 lang 标注和 aria-live 原词→译词公告；reduced-motion 保留功能。

语义质量样例的真实 provider 验收与 mock 的调度／布局验收分开记录。若需要发送私人书籍片段做线上诊断，先取得该片段和用途的明确许可；本次实现默认使用合成样例。

完整测试、类型检查和生产构建通过；source/projection/CFI 适配与真实浏览器回归是全部三项的交付条件。只完成预取或只完成开关不宣称整套功能完成。

## 10. 发布和回滚

实现前保留当前可用版本。完成后先核对 GitHub main，非强制更新经过验收的改动；部署前读当前生产版本并核对，发现不一致先评估差异。

保留现有 DeepReader release 隔离规则：备份代码／构建和一致 SQLite 快照，校验环境、Nginx、app／worker unit、上传文件哈希；只停止和启动 DeepReader web。构建采用已有 app 专属资源限制，worker 和其他服务不动。失败回滚代码／构建，不用旧数据库覆盖运行中产生的数据。

部署后验证登录页、受保护 API、静态资源、app／worker 状态、SQLite 完整性和配置／书籍哈希。已开启的 Chrome Apple Events 仅用于用户指定的终端，本地脚本不搜索或读取其他标签里的账号数据；完成后提示用户关闭临时开关，不声称已自动关闭。
