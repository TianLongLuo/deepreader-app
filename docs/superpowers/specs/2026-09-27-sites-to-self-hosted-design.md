# Sites 功能回迁至自建服务器版

## 已确认目标
用户已授权直接更新 TianLongLuo/deepreader-app 的 main，不要求 PR。将 Sites 版 UI 和新增功能迁回原项目，保留自建服务器运行能力。此次不部署用户服务器，不更改当前 Sites 网站，也不迁移线上账号、书籍或密钥。

## 已核实基线
- 原仓库 main：fb2c77dd01e152ad67df3af346bb2e6e52213d5f。
- Sites 已发布版本 7，源码：ed422a6ae1dfd6ce98b37561991847806b5c2307。
- 原版使用 Next.js 16.2.3、Node.js、Prisma/SQLite，并有本地/S3 文件存储和 Ubuntu 部署脚本。
- 两份源码初步有 75 个同路径文件不同；新增文件中包含 UI、词库、PDF 静态资源，也包含不应带入的 Sites 专用框架与生成物。

## 迁移策略
采用“原仓库为主，按功能迁入”，不整体替换工程，也不把 Sites 的 Git 历史强推到 GitHub。保留原有 main 历史，以普通新提交更新 main；推送前重新检查远程，若有人新增提交先整合而不是覆盖。

### 1. UI 与阅读器
迁入统一主题、书库、上传页、生词库、设置和后台界面；迁入独立浮窗、贴近选词定位、拖动缩放及尺寸记忆、独立释义语言、单词/段落分析分流和简洁语境解释。保留 EPUB/PDF 阅读与书签、笔记、进度等功能。PDF worker、字体和 CMap 资源与依赖版本配套。

### 2. 自托管词库
完整迁入已下载的英文、西语词库、许可证、来源清单、导入及校验脚本。接口保留 /api/dictionary，底层改为 Node.js 文件读取与 gzip 解压，不依赖 Cloudflare ASSETS，不调用第三方词典接口。按词定位分片，保持有界缓存和输入检查。未收录词返回 404；缺失或损坏文件返回明确服务错误。已有 IPA 按原数据展示，不生成虚构音标；录音不打包、不外链，设备朗读保持现状。两种源语言的词典释义均为英文，AI 语境翻译独立工作。

### 3. 用户、权限与数据
以原 Prisma 数据层及存储接口为基础，按需迁移 Sites 的注册、登录、管理员控制、AI 设置权限及保护措施。不复制 D1/Drizzle 兼容层，不替换为 Prisma WASM。管理员通过服务器环境变量初始化；密码哈希存储，密钥不进入代码仓库。若功能需要新增数据结构，提供增量迁移；禁止重置、清空现有数据库，部署前说明备份与回滚。

### 4. 上传和后台处理
保留原服务器本地/S3 存储及 Node 后台处理能力。新版上传 UI 所依赖的分块接口须适配服务器存储，或通过同等用户体验的原服务器上传流程完成；不得留下 R2 专用调用。落实文件大小、所属用户、分块完整性和失败清理检查。迁入适用于服务器的阅读/解析修复，不照搬仅为 Workers 限制造成的功能删减。

### 5. 部署与配置
保留 next build / next start 的标准服务器方式及 Ubuntu 部署路径，更新环境变量示例和部署说明。纠正现有 DEPLOY.md 中“已包含数据库、上传书籍、密钥”的旧说明：公开仓库不携带这些私有运行数据。已有服务器必须保留原 ENCRYPTION_KEY，避免旧 AI 配置失去解密能力。本次不强制引入 Docker、替换数据库产品或要求 Redis。

## 排除项
不迁入 .openai、Wrangler、Vinext、Cloudflare bindings、Sites OAuth、构建缓存、node_modules、开发数据库、上传书籍、日志、cookie 或实际 .env。保留合法公开词库和 PDF 资源的许可。不改变现有 Sites 发布版本。

## 验收与交付
1. Node 环境类型检查、单元/回归测试、Next.js 生产构建通过。
2. 实际文件词库查询 occasion / niño / casa 成功，关闭外部词典网络依赖仍可查词，缺词错误明确。
3. 本地服务器验证注册登录、权限隔离、书籍上传、EPUB/PDF 阅读、浮窗不挤动正文、拖动缩放记忆、AI 配置入口。AI 请求使用模拟响应，不消耗付费模型调用。
4. 检查运行路径没有 Cloudflare 专用依赖；检查提交不含私有数据或密钥。
5. 完成后以普通提交更新 GitHub main，核实远程提交 SHA，提供提交链接与自建部署说明。只在全部必要验证完成后报告迁移完成。
