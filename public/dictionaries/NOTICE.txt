DeepReader changes: NFC/lowercase lookup keys; Latin single-word filtering;
case variants merged; parts of speech, definitions and IPA retained; hashed,
gzip-compressed JSON shards. Omitted fields include synonyms, alternate forms,
Wikipedia links and external audio. No audio files are included or hotlinked.

The same CC BY-SA 3.0 license applies to these adapted dictionary data files.
Each API result includes a link to the original Wiktionary entry and credits.
The versioned manifest records download URLs, SHA-256 checksums, word counts,
IPA counts and shard checksums. The version date is the download/import date,
not a claim about the age of the original Wiktionary dump.

The English and Spanish headwords both have English dictionary definitions.
AI context interpretation/translation is separate and is not dictionary data.
